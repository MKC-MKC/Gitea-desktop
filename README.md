Проект, на который многие не решались, но решилась нейронка.

Следующая фишка была сделана для персонального использования.
В корне проекта ожидает файл `app-info.json`
```json
{
    "name": "Название твоего приложения",
    "tags": [
        "2",
        "2.0",
        "2.0.0",
        "latest"
    ]
}
```
Следующая фича, позволяет в один клик изменить семантику пакета и опубликовать релиз с 2.0.0 тегом.

Исправлены очень старые баги:
- Если remote релиз был удалён, то локально он не удалялся.
- Если ещё не отправленному релизу с выданным тегом сделать undo commit, то со следующим пушем, тег которого не должно было быть, отправлялся на сервер.
- Так же если пачке коммитов сделать undo, ТО не удалялост, теперь всё удаляется...
- И что-то ещё исправили...

- Разрешил делать Undo commit владельцу, если коммит был уже загружен. Аккуратнее с этой игрушкой! :)

- Выпилил Github copilot... Дичь...

- Что-то пытался костылить с иконкой приложения, что есть то есть...

- Двойной клик на файл, теперь открывает его в системном редакторе по умолчанию, а не во внешнем IDE.

- Добавлено сочетание Cmd/Ctrl+Shift+C для копирования абсолютного пути текущего репозитория.

> Ранее всё сохранялось плоско в
`$PWD/Documents/GitHub`
> сейчас всё в
`$PWD/gitea`

> Сортировка скачиваемых репозиториев по организации (из коробки).
> Когда качаете репо, например: `https://github.com/MKC-MKC/Gitea-desktop`
> тогда сохранится как
`$PWD/gitea/MKC-MKC/Gitea-desktop`
